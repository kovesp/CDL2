# CDL2 Compiler & Laboratory V1

1. In compiler mode parses a CDL2 program file into a syntax tree and generates code for PoweerShell.
  
2. In Lab mode shows a GUI window wherre Lab commands may be entered and excuted. Under development.

Note: I don't have any official documentation for CDL2 itself or the Lab apart from the monograph of
Maik Stahl and Kees Koster *Inplementing Portable and Efficient Software in and Open-Ended Language*.
The rest is from memory and for the Lab, parallels from the MProlog PDSS subsystem which was based on
the Lab.
